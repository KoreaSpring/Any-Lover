两种陪伴方式

🪟 桌宠模式 · Pet Mode

透明悬浮、始终置顶、空白处可穿透点击。TA 静静待在桌面角落，需要时随时说话。

完整聊天窗口，带历史记录、字幕与感知入口。专注深聊时的最佳形态。

如何工作

继承自 Open-LLM-VTuber，融合为一个开箱即用的桌面应用。

1

下载安装

下载 Windows 安装包，一键安装。内置后端运行时，无需配置环境。

2

一次配置

填写云端大模型 API/Key，或选择本机 Ollama；整合版则完全免配置。

3

开始陪伴

桌宠启动，语音或打字聊天。托盘随时切换桌宠 / 窗口模式。
